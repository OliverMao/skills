# 写真 Video Skill 约定

## 真源与发行

- 本目录是唯一可编辑真源；独立 GitHub 仓库和知识站下载只接收构建生成的发行快照。
- 本项目为独立的新项目，不携带任何历史版本或历史发行物记录。
- 当前公开许可证为 MIT，版本从 `0.1.0` 开始。
- 每次公开发布必须同步更新 `SKILL.md` 的 `metadata.version` 与 `CHANGELOG.md`，并通过 `scripts/release_public_skill.py --skill kagnet-xiezhen-video` 构建。
- 本 Skill 不绑定具体视频平台或模型；视频生成由宿主智能体按当前可用工具执行，本包只输出可移植中文拍摄指令与参数。

## 行为保护

- 普通视频提示词请求默认不生成；只有用户明确要求才进入真实生成。
- 身份参考只决定人物身份，写真（视频）参考决定妆发、服装、场景、光线流动、事件弧、运镜与成像。
- 重做必须回到原始输入重新编译；上一段生成视频只用于诊断，除非用户明确要求编辑上一段。
- 没有视频生成工具时必须降级为 Prompt 与拍摄方案交付，不得伪造生成结果。
- 不绑定具体平台字段、模型名或 API；时长、比例、循环等写成可移植自然语言参数。
- Eagle、个人知识库、私有路径和其他个人 Skill 不得成为公开包的必要依赖。

## 验证

- 修改后运行合同测试、YAO 结构校验、触发正反近邻评测与仓库检查；结构测试不等于真实生视频回归。
- 公开构建必须通过白名单、安全扫描、版本与许可证门禁；正式发布还需干净真源、公开仓库和发行物回读。
- 涉及生视频行为变化时，另做真实生成与原作对照验收。
