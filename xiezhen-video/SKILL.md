# kagnet-xiezhen-video

## 目标

把写真视频意图编译成可直接使用的中文视频生成 Prompt；当用户明确要“换个人拍同一套视频写真”并要求生成时，把参考组还原成可执行的视频拍摄企划，由当前环境提供的视频生成工具生成指定数量的短视频，并完成质量检查与可追溯交付。本 Skill 不绑定任何具体平台、模型或 API：视频生成由宿主智能体根据当前可用工具执行，本 Skill 只负责把企划编译成任何平台都能消费的中文拍摄指令与可移植参数。Eagle 只在当前环境可用时作为附加归档，不是完成任务的前提。

## 入口判断

先选择一种模式：

- 用户提供一组写真参考并表达“照这套拍段视频、换个人拍一套视频、像去同一家店拍、复刻这套视频写真企划”等意图时，进入**视频企划复拍**。读取 [视频企划复拍工作流](references/production-reshoot.md)；只有用户明确要求生成视频才执行完整生成闭环。
- 用户说“系列母版、一整套系列、系列规划、固定格式”时，输出视频系列母版。
- 用户只说“变体、同系列、创作变体、仿拍扩展”，但没有表达完整视频企划复拍意图时，输出同系列视频变体关键词链。
- 用户说“完整、详细、精准控制、复刻视频 Prompt、分镜脚本”时，输出详细视频提示词。
- 用户说“抽卡、网页端、大量生成、短关键词、开盲盒”时，输出 6–8 行抽卡短视频关键词。
- 用户给一段视频或一组参考并要求拆解时，输出视频关键词；短视频先提取共同视觉 DNA 与运动语法，再列单段差异。用户明确“只拆解、不生成”时不得进入生成闭环。
- 用户给出 `主题：`、人物类型、`关键词：` 三段骨架时，直接按 [视频提示词逻辑与模板](references/prompt-logic.md) 的三段式规则编译，不依赖包外模板。
- 用户说“文化视觉溯源、文化元素、往外扩展灵感”时，只根据当前可见证据区分事实、强关联和灵感联想；需要外部史实或来源时先真实检索，不依赖私有知识库方法。

普通视频提示词、变体、拆解与模板规则读取 [视频提示词逻辑与模板](references/prompt-logic.md)。

## 参考素材职责

1. 参考素材承担身份还是视频摄影参考，必须先分清。用户另外提供人物形象图/片中人物画面但没有说明用途时，只问一次：它是要保持同一位人物，还是只借人物气质？
2. 人物身份参考只回答“她是谁”，保持主要五官辨识度；目标视频接管妆容、发型、服装、场景、光线流动、事件弧与时间连续性。
3. 视频方案参考只回答“这套视频怎样被拍出来和动起来”，不承担人物身份。Prompt 必须正向写入：`本段重新生成一位「【原创女性类型】」类型的成年原创女性，不要继承参考素材中人物的脸。`
4. 没有人物身份素材时，根据写真类型自动替换 `【原创女性类型】`，以人物好看、动作自然且画面成立为优先；不检查组内是否为同一张脸，也不增加生成脸与参考人物逐一比较的验收层。

## 共享原则

1. 先判断视频为什么成立，再写细节。光线必须写清来源、方向、随时间在人身与环境中的演化结果；机位一旦开始运动，光源、遮挡物与环境反射固定在世界空间中，先重建运动过程中的受光关系，再编译 Prompt。
2. 时间先于构图：每段视频先确定一个连续动作弧（发生—推进—结果），再写镜头运动（起幅、运动方式、落幅），再写静止元素（妆造、服装、场景、背景层级）如何被时间穿过。
3. 风格写成可观察的成像机制与运动机制，不用“高级、氛围感、电影感、丝滑运镜”代替白平衡、曝光、反差、高光、锐度、噪点、压缩、景深，以及镜头运动的时间结构。
4. 穿搭只写服装，饰品放入道具；场景与道具分开。
5. 默认人物为成年年轻女性，强调成年后的青春、灵动和生命力；不写未成年或儿童化表达。
6. 有人物身份素材时把身份与表情分开控制；身份素材只提供稳定五官锚点，本段的动作弧与表情由目标视频中的具体人物事件决定，不默认继承身份素材中的中性眼神和嘴角状态。
7. 视频企划复拍的每一轮都从原始人物素材、原始视频参考和本轮重新编译的完整 Prompt 开始；上一轮生成视频只用于诊断问题。除非用户明确要求编辑上一段视频，不把任何生成视频作为新一轮视觉输入，也不在旧 Prompt 上追加补丁式修图指令。
8. 新一轮结果直接对照原始视频参考判断；“比上一轮更顺滑更有风格”只表示相对改善，不能替代原作保真、结构检查和用户验收。
9. 原作若依赖欠曝、失焦、堵黑和偶发抓拍，必须启动去商业抛光层：把连续暖色轮廓光、皮革折面塑形、稳定脸部焦点、正面回填和英雄式运镜改写为原作支持的物理结果；精致 editorial 视频原作不套用这条降质规则。
10. 皮肤质感必须区分纹理与反射；近景、直闪或高光妆面要按景别控制底妆反射和高光范围，并说明高光是否随时间移动。
11. 视频拆解只写可见事实；不确定内容标为“疑似”，不编造品牌、摄影师、器材、剪辑软件或历史来源。
12. 用户没有明确要求生成时，只交付视频 Prompt 或拆解结果，不产生视频、Eagle 资产或项目记录。
13. 默认不添加任何署名或水印（包括画面水印与片尾文字）。只有用户明确要求时，才加入用户指定的署名文字；不得默认使用 `kagnet` 或替用户决定署名内容。
14. 跨镜头与跨段一致性：同一段或同一组内的主要人物、妆发、服装、主导光线与场景应保持一致；只在允许抽帧的平台提示下使用循环、定格、回放等参数，不把“一致性”伪装成对具体平台的绑定。

## 输出

- 普通模式直接交付用户触发的视频 Prompt 或拆解结果，不输出内部分析模块。
- 视频企划复拍必须在对话中交付简短拍摄方案摘要、实际视频（或对应编号与失败原因）、每段完整 Prompt、参考职责、质量状态与追溯记录。Eagle 可用且归档成功时再附 Eagle ID；不可用或归档失败不影响上述核心交付。
- 默认中文，仅保留模型更易理解的摄影与运动英文词。
- 单段视频默认时长 4–7 秒，用户指定时服从用户；比例默认继承参考素材的主要画幅。

## 环境兼容

在有本地项目规则的工作区中，先读取当地 `AGENTS.md` 和适用的视频生成方法；项目规则可以补充归档与记录要求，但不得把署名或 Eagle 变成跨环境默认前提。本 Skill 不绑定具体视频平台：环境提供视频生成工具且用户明确要求生成时，才由宿主智能体调用对应工具执行真实生成；没有视频生成工具时，明确停在 Prompt 与拍摄方案交付层，不得声称已经出视频。检测到 `kagnet-codex-image-to-eagle` 且 Eagle 可用时，视频产物可以被同套流程归档到 Eagle；未安装、未连接、同步失败或用户不使用 Eagle 时，继续在对话中完成全部核心交付。
